# CampusCart

CampusCart is a campus-focused e-commerce platform that helps students buy, sell, and discover products within their own campus.

## Features

* 🛍️ Buy and sell products within campus
* 🔎 Browse and search available products
* 👤 Student user profiles
* 📦 Product listings with details
* 🤝 Connect campus buyers and sellers
* 📱 Simple and responsive interface

## Tech Stack

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** JWT
* **Styling:** CSS

## Project Goal

CampusCart makes buying and selling products within a college campus simple, convenient, and accessible by connecting students in one platform.

**CampusCart — Buy. Sell. Connect.**
